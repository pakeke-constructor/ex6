
# tasks:

Tasks are essentially just a big list of markdown files.
- Each task is a .md file

Think kinda like claude-plans, but a bit more formalized,
and with a bunch of extra metadata.

Files are kinda nice, because they persist over context,
manage dependencies a bit better, and are small enough to be reasoned about via light and cheap LLMs like gemini flash.



Since it's just markdown, it's also human-readable (and editable) too!
